# Calibración HSV y búsqueda — Fase 03.4-R

Fecha: 25/11/2026. Los perfiles son propuestas de software; deben ajustarse con piezas y fondo reales. El operador reportó comunicación estable, video correcto, direcciones manuales probadas y ambos servos funcionales. Estas observaciones no fueron reproducidas durante el desarrollo.

1. Abra Configuración → Visión artificial. Con el robot desarmado, seleccione **90° izquierda** si la imagen cruda está girada a la derecha. Equivale a `vision.rotation=270` horario. La configuración local de este equipo pasó de 0 a 270. Una instalación nueva mantiene 0 hasta que el operador elija; cargar el programa no suma rotaciones. No cambie los ajustes digitales si no hace falta: se preservan neutros.
2. Abra **Calibrador de colores…**. Comparar Original, Procesada y Máscara usa el mismo flujo de cámara; no abre otra conexión. Aquí Original significa imagen normalizada, sin overlays ni ajustes digitales. El PNG original de captura conserva los bytes de la imagen recibida.
3. Para rojo, seleccione rojo y Muestra. Arrastre dentro de la pieza evitando fondo, brillos y contorno. Se congela el frame durante el arrastre; al soltar se rechaza si ya está atrasado. El muestreo usa las coordenadas del label, sin las bandas del visor.
4. Repita con rojo oscuro y claro. El tono es circular: muestras alrededor de H=0/179 generan dos intervalos. La propuesta muestra centro circular, mediana S/V, dispersión y cantidad de píxeles útiles. El cálculo conserva mediana HSV y percentiles; excluye S<40, V<20 y reflejos claros con poca saturación. Mezclar varios colores en una misma selección produce propuestas demasiado amplias: reduzca la selección.
5. Repita para verde y azul en distintas iluminaciones. Una muestra añade intervalos al borrador. Puede eliminar una muestra o editar cada intervalo: nombre, habilitado y seis límites enteros H/S/V mínimo, H/S/V máximo. H está entre 0 y 179; S/V entre 0 y 255. Hasta 16 intervalos por color. No se elimina el último intervalo: puede deshabilitarlo.
6. Para nuevas tonalidades agregue muestras o intervalos. Los intervalos habilitados del mismo color se unen con OR. Un solapamiento HSV entre colores muestra advertencia; una región con cobertura significativa de más de un color se descarta como incierta, sin asignar el primer color arbitrariamente.
7. Seleccione ROI de búsqueda y arrastre sobre la imagen. La región se guarda normalizada, se muestra y puede habilitarse o volver a imagen completa. Es independiente de la ROI de agarre. Revísela después de cambiar orientación o montaje.
8. En Filtros / ROI ajuste área mínima absoluta/relativa, área máxima relativa, ancho/alto mínimos, aspecto, solidez, extensión, proporción de color y contacto con bordes. Active regiones segmentadas y descartes para comparar con candidatos válidos. Los nombres técnicos corresponden a campos documentados en `app/vision_config.py`; `reject_border` usa True/False. Una región segmentada todavía no es una figura reconocida.
9. Compare el perfil Original con **Ampliado experimental**. Este último usa rojo H=0–15/165–179, S≥55,V≥35; verde H=35–89,S≥45,V≥35; azul H=90–135,S≥45,V≥35. Requiere tres frames distintos para confirmar. Original mantiene los umbrales previos y confirmación en un frame por compatibilidad. Ajuste `tracking.confirm_frames` a 3 o más al calibrar un perfil propio.
10. En Perfiles puede crear/duplicar el borrador, seleccionar, renombrar y eliminar perfiles propios. Original y Ampliado experimental están protegidos. El catálogo `vision_profiles.local.json` es privado. Seleccionar solo previsualiza; no revierte la orientación de la cámara. Editar un perfil protegido lo identifica como Borrador de ese perfil; el catálogo Original conserva sus valores. Restablecer Original y eliminar requieren confirmación. Restaurar ajustes activos descarta cambios locales.
11. Pulse **Aplicar y guardar** y confirme, con el robot desarmado y en reposo, sin ráfaga activa. Se valida y guarda el perfil; no se reconstruyen comunicaciones ni cámara. Cancelar/cerrar descarta el borrador. La aplicación rechaza aplicar si hay actuadores activos, estado real no confirmado/fresco o captura reservada. La preparación local sin cámara puede hacerse desarmada; no certifica el estado físico de un robot desconectado.

El trabajador del calibrador procesa sobre el último frame de la cámara existente y conserva un solo resultado. El procesamiento ocurre fuera de Tk; las revisiones impiden publicar un resultado de un borrador anterior. Cierre el calibrador antes de cambiar la configuración general de conexión. STOP y Escape siguen disponibles; calibrar no arma ni mueve el robot.

Los IDs se asocian por color, proximidad y relación de áreas. El centroide y la posición se suavizan exponencialmente. La confirmación exige frames distintos consecutivos; tras pérdidas se exige nueva confirmación, conservando temporalmente el ID según `lost_frames` y `max_gap_s`. Un frame repetido no aumenta las confirmaciones ni renueva la vida del track. Cambiar generación o perfil reinicia el seguimiento. IDs son locales a esa generación y no identifican físicamente una pieza a largo plazo.

CNN no cargada: el resultado muestra «Azul — figura pendiente de clasificación CNN» o equivalente. Clase predicha, confianza y destino permanecen desconocidos. No hay navegación, lógica difusa, heurística ejecutable ni movimiento autónomo.
